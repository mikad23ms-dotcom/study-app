        طريقة الحصول على المفاتيح المجانية 🔑

        1. مفتاح Google Gemini

        1. ادخل على موقع: Google AI Studio
        2. سجل دخول بحساب جوجل بتاعك (هتلاقي زرار Create API Key).
        3. لو ظهرتلك رسالة اضغط Get API key وبعدين Create API key in new project.

        1. ادخل على موقع: Groq Cloud

        3. اضغط على Create API Key.

        كيف تستخدم التطبيق في دقيقة واحدة؟ 🚀

        بسيط وسهل ومصمم خصيصاً لمساعدتك على التفوق بأقل مجهود

        📚
        1. نزل مواد مرحلتك بضغطة زر

        مش هتحتاج تكتب المواد يدوي! اضغط على زر "تنزيل مواد مرحلتي" والتطبيق هينزل كل موادك (عربي، كيمياء، إنجليزي...) بألوانها فوراً.

        📝
        2. اكتب مهام مذاكرتك اليومية

        كل يوم الصبح اكتب الدرسين أو الـ 3 اللي عاوز تذاكرهم. كل ما تخلص درس دوس عليه علامة صح ✅ واكسب نقاط خبرة وتنافس مع زمايلك!

        🗓️
        3. جدول حصصك وسناترك وتنبيهات الأذان

        سجل مواعيد دروسك وسناترك ليرتبها التطبيق أسبوعياً، مع منبه لمواقيت الصلاة وورد القرآن لتنال البركة والتركيز.

        🤖
        4. المساعد الذكي وتايمر التركيز (بومودورو)

        شغل المايك في الحصة ليسجل صوت المستر ويلخص الدرس، أو صور أي مسألة تقف معاك واسأله فيها، وشغل تايمر الـ 25 دقيقة لتمنع تشتت الموبايل!

        تثبيت التطبيق على شاشة موبايلك في ثواني! 📲

        آمن 100% معتمد رسمياً من جوجل وآبل (بدون أي تحميل لملفات!)

        أنت فاتح الرابط داخل واتساب!

        عشان تثبت التطبيق، اضغط على الـ 3 نقط بأعلى شاشة واتساب (⋮) ⬅️ واختار (الفتح في متصفح Chrome)، وساعتها هيتثبت على شاشتك بضغطة زر واحدة!

        لهواتف الأندرويد (Google Chrome / Samsung):
        1. اضغط على الـ 3 نقط (⋮) بأعلى شاشة المتصفح.
        2. اضغط على خيار (تثبيت التطبيق) أو (إضافة إلى الشاشة الرئيسية / Add to Home screen).
        3. 🎉 مبروك! هتلاقي أيقونة التطبيق نزلت على شاشة موبايلك زي أي تطبيق رسمي!
        لهواتف الآيفون (Safari):
        1. اضغط على زر المشاركة (⎋) بأسفل شاشة سفاري.
        2. مرر للأسفل واضغط على (إضافة إلى الشاشة الرئيسية ➕).
        3. اضغط (إضافة / Add) وهيشتغل معاك بكامل الشاشة!
